# Debug Changelog — 20260403_095155_428283

## Root Causes Found

### Issue 1 — Backend: `Cannot find module './generated/prisma_ahbb/index.js'`
The Prisma client is generated to `src/generated/prisma_ahbb/`. When NestJS compiles TypeScript to `dist/`, the compiled `dist/src/prisma.service.js` resolves `./generated/prisma_ahbb/index.js` relative to `dist/src/` — a path that never existed because NestJS only compiles `.ts` files and does not copy extra files to `dist/` unless told to via `assets` in `nest-cli.json`.

### Issue 2 — Frontend: `El sistema no puede encontrar la ruta especificada`
The folder name `academia-h&b` contains `&`, which is a command separator in CMD. When `concurrently` spawns `cd /d "academia-h&b"` as a sub-shell command, CMD truncates the path at `&`, interpreting the `&` as a shell operator even inside a double-quoted string (due to how `concurrently` passes multi-level escaped strings to `cmd.exe`).
