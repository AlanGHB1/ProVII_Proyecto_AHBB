## Changes Made

### 1. Hardened Session Generation Logic
- **File:** `academia-backend/prisma/sp_generar_sesiones_ahbb.sql`
- **Change:** Added a check on the very first iteration of the loop. If the `fechaInicio` doesn't result in a session (meaning the start date day doesn't match any scheduled day), the procedure now throws a clear `RAISE EXCEPTION`. This prevents the system from silently skipping days and starting courses on the "wrong" day.

### 2. Implemented 'BEFORE INSERT' Consistency Trigger
- **File:** `academia-backend/scripts/create-sp_ahbb.cjs`
- **Change:** Added a new trigger `trg_validar_inicio_sesion_ahbb` on the `td_sesion_curso_ahbb` table. This trigger fires before every session insert. If it's the first session (`nroSesion = 1`), it verifies that its date matches the parent course's `fechaInicio`. This provides a final, low-level guarantee of data integrity as requested.
