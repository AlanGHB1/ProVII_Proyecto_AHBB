## Changes Made

### 1. Relaxed Date Validation in Backend
- **File:** `academia-backend/src/cursos/cursos.service.ts`
- **Change:** Modified `validarFechaInicio_ahbb` to allow ADMIN users to set any `fechaInicio`, including dates in the past. This allows back-filling historical or already-started courses.
- **Revert:** Remove the `if (rol_ahbb === 'ADMIN') return;` check (line 373).

### 2. Standardized Backend Date Outputs (YYYY-MM-DD)
- **File:** `academia-backend/src/cursos/cursos.service.ts`
- **Change:** Updated `mapearCurso_ahbb` and session mapping in `obtenerSesiones_ahbb` to convert all `DateTime` fields into `YYYY-MM-DD` strings using the UTC helper. This completely eliminates the 1-day timezone shift previously seen in the frontend.
- **Revert:** Remove `this.formatearFechaISO_ahbb` calls in mappers.

### 3. Fixed Frontend Date Parsing (No Shifts)
- **Files:** 
  - `academia-h&b/src/components/cursos/TablaCursos_ahbb.vue`
  - `academia-h&b/src/components/cursos/FormularioCurso_ahbb.vue`
- **Change:** Updated components to use `T12:00:00` or UTC extraction when parsing dates. This ensures that a date like "2026-02-26" is always rendered as Feb 26th, regardless of the browser's local timezone.
- **Revert:** Revert back to using standard `new Date(fecha)` on these files.

### 4. Added Calendar Auto-navigation
- **Files:**
  - `academia-h&b/src/components/horarios/CalendarioDinamico_ahbb.vue`
  - `academia-h&b/src/pages/compartidas/HorariosView_ahbb.vue`
- **Change:** Exposed `cambiarVistaAMes_ahbb` in the calendar component and added a watcher in the View. When a specific course is filtered in the schedules view, the calendar now automatically moves to the month and day of that course's start date.
- **Revert:** Remove `defineExpose` in calendar and the `watch` logic in the view.
