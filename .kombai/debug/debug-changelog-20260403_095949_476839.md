# Debug Changelog — 20260403_095949_476839

## Additional Root Causes Found

### Issue 1 — Assets fix from session 20260403_095155_428283 didn't work
`nest-cli.json` `assets` copy is unreliable because of `deleteOutDir: true`: NestJS deletes `dist/` first, then compiles TypeScript, then is supposed to copy assets — but this last step was not happening reliably. The `dist/src/generated/` folder never appeared.

### Issue 2 — No `[FRONTEND]` output
The `-k` flag in `concurrently` kills **all** processes when **any one exits**. The backend crashed immediately after startup → concurrently sent SIGTERM to the frontend before it printed anything. The frontend was not broken — fixing the backend will restore frontend output.
