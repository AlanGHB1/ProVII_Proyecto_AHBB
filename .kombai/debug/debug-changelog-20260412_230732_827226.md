## Changes Made

### 1. Unified Session Generation Logic
- **File:** `academia-backend/prisma/sp_generar_sesiones_ahbb.sql`
- **Change:** Updated the Stored Procedure to iterate through ALL matches in the `p_dias_semana` array for a given calendar day. This ensures that if a course has multiple blocks per day (e.g., 8-10 AM and 2-4 PM on Monday), all sessions are generated. This fixes the previous "desface" (mismatch) where only the first block was processed.
- **Revert:** Revert to the version that uses `EXIT` after finding the first match.

### 2. Standardized Date Formatting in Backend
- **File:** `academia-backend/src/cursos/cursos.service.ts`
- **Change:** Added a private helper `formatearFechaISO_ahbb` that uses `getUTCFullYear`, `getUTCMonth`, and `getUTCDate`. This ensures that `DATE` fields from Postgres are consistently mapped to `YYYY-MM-DD` strings regardless of the server's local timezone, preventing dots in the calendar from shifting to the previous or next day.
- **Revert:** Revert lines 849-880 to use `toISOString().split('T')[0]`.

### 3. Synchronized Status Logic in Store
- **File:** `academia-h&b/src/stores/cursosStore_ahbb.js`
- **Change:** Updated the `cursosActivos_ahbb` getter to include both `activo` and `iniciado` statuses. This ensures the summary cards correctly reflect the total number of running courses.
- **Revert:** Revert line 47 to only check for `activo`.

### 4. Improved Calendar Marker Accuracy
- **File:** `academia-backend/src/cursos/cursos.service.ts`
- **Change:** In `obtenerSesiones_ahbb`, the logic now uses the standardized date formatter for both confirmed sessions and tentative start-date markers. It also ensures that for tentative markers (courses with 0 students), the local date components are preserved to match the intended start day.
- **Revert:** Same as Change 2.
